Project overview

ForgeBlog AI is an autonomous technical blog-generation system that turns a topic into a structured technical article with research, parallel writing, and supporting visuals. A Streamlit interface exposes the generation process, live progress, Markdown preview, image preview, and downloadable output.

Topic routing

A router agent classifies the topic into closed-book, hybrid, or open-book mode and decides whether web research is needed.

Research and evidence

When research is needed, Tavily search gathers source material and structured evidence for the writing workflow.

Parallel section writers

The orchestrator creates a blog plan and multiple writers draft individual sections in parallel.

Visuals and export

A reducer merges sections in order; image planning and the FLUX image agent create supporting visuals, with Markdown and images saved as outputs.

Multi-agent pipeline

  • 1. Router agent: classifies the topic and decides whether web research is required.
  • 2. Research agent: uses Tavily to gather authoritative sources, extract content, and build an evidence pack when needed.
  • 3. Orchestrator agent: creates the outline and writing constraints, including title, audience, tone, sections, and guidelines.
  • 4. Parallel writer agents: generate sections concurrently.
  • 5. Reducer / merger: combines the generated sections in the correct order.
  • 6. Image planner: decides where images are useful and inserts image placeholders.
  • 7. FLUX image agent: generates technical visuals and saves image files.
  • State and checkpoints: LangGraph state stores intermediate messages and results and supports resumability.

Interface and outputs

  • Topic input and blog generation controls
  • Live progress and execution logs
  • Markdown preview and download
  • Generated image preview and image files
  • Citations / source links when research is used
  • Saved Markdown outputs, images, and JSON execution logs
